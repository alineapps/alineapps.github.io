お問い合わせ

不具合の報告・ご要望・ご質問は、GitHub の Issue で受け付けています（GitHub のアカウントが必要です）。

Issue を作る

不具合の場合は、次のことを書いていただけると助かります。

  • Clipboarder のバージョン（設定 > 情報）
  • Windows のバージョン
  • 何をしたときに、どうなったか

Issue は公開されます。コピーした内容やパスワードなど、人に見られたくない情報は書かないでください。

Support

Bug reports, requests and questions are handled through GitHub Issues (a GitHub account is required).

Open an issue

For bug reports, please include:

  • Clipboarder version (Settings > About)
  • Windows version
  • What you did and what happened

Issues are public. Please do not include anything private, such as copied content or passwords.
